# Security Policy

## Supported versions

Security fixes are applied to the current 2.x line (the floating `v2` tag). The `v1` tag is frozen and does not receive security fixes.

| Version | Security fixes |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

## Reporting a vulnerability

Report security vulnerabilities in this repository privately. Do not open a public GitHub issue, and do not post proof-of-concept details in a public pull request or discussion.

Use **GitHub private vulnerability reporting**:

<https://github.com/evidence-gate/evidence-gate-action/security/advisories/new>

If you cannot use that form, email [support@evidence-gate.dev](mailto:support@evidence-gate.dev). Include the affected version or tag, what you observed, and steps to reproduce if you have them.

We will acknowledge reports sent to that address and coordinate the fix through a GitHub Security Advisory.
